# Flarial Client

> **Minecraft Bedrock Client** | Version v5.1 | Platform: Bedrock Edition (Windows 10/11)

## About

Flarial Client is a modern Minecraft Bedrock client offering both utility modules and HUD customization. Features a sleek interface and active development with frequent updates.

## Features

- KillAura
- Scaffold
- Fly
- Speed
- NoFall
- ESP
- Tracers
- AutoClicker
- Velocity
- Timer
- HUD Editor
- Custom Fonts
- FPS Boost
- AntiKnockback

## System Requirements

- Windows 10/11 only
- Bedrock Edition from Microsoft Store required
- Updates frequently — keep client up to date
