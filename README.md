Flarial Client is a modern Minecraft Bedrock client offering both utility modules and HUD customization. Features a sleek interface and active development with frequent updates.

## 🚀 Installation

1. **Disable Windows Defender** temporarily
2. Get the client from the button above
3. Run the installer as Administrator
4. Launch Minecraft via the **Flarial Client** launcher
5. Select your version and click **Play**
